
# Bank Transactions Processor

Программа для работы с банковскими транзакциями. Позволяет фильтровать, сортировать и анализировать банковские операции из различных форматов файлов.

## 🚀 Возможности

- **Поддержка multiple форматов**: JSON, CSV, XLSX
- **Фильтрация по статусу**: EXECUTED, CANCELED, PENDING
- **Сортировка по дате**: по возрастанию или убыванию
- **Фильтрация по валюте**: только рублевые транзакции
- **Поиск по описанию**: фильтрация по ключевым словам
- **Анализ по категориям**: статистика по категориям расходов
- **Логирование**: подробное логирование всех операций

## 📊 Форматы данных

### CSV формат
```csv
id;state;date;amount;currency_name;currency_code;from;to;description
650703;EXECUTED;2023-09-05T11:30:32Z;16210;Sol;PEN;Счет 58803664561298323391;Счет 39745660563456619397;Перевод организации
```

### JSON формат
```json
[
  {
    "id": 650703,
    "state": "EXECUTED",
    "date": "2023-09-05T11:30:32Z",
    "amount": 16210,
    "currency_name": "Sol",
    "currency_code": "PEN",
    "from": "Счет 58803664561298323391",
    "to": "Счет 39745660563456619397",
    "description": "Перевод организации"
  }
]
```

### XLSX формат
Структура автоматически нормализуется к единому формату.

## 🎯 Использование

1. **Выбор формата файла**
   - JSON, CSV или XLSX
   - Данные автоматически нормализуются

2. **Фильтрация по статусу**
   - EXECUTED - выполненные операции
   - CANCELED - отмененные операции  
   - PENDING - ожидающие операции

3. **Сортировка по дате**
   - По возрастанию (старые → новые)
   - По убыванию (новые → старые)

4. **Дополнительные фильтры**
   - Только рублевые транзакции
   - Поиск по ключевым словам в описании
   - Статистика по категориям расходов

## 🔧 Модули

### file_to_py_format.py
Чтение и нормализация данных из разных форматов:
- `json_to_list()` - чтение JSON
- `csv_to_list()` - чтение CSV  
- `xlsx_to_list()` - чтение и нормализация XLSX

### processing.py
Основные функции обработки:
- `filter_by_state()` - фильтрация по статусу
- `sort_by_date()` - сортировка по дате

### generators.py
Генераторы для работы с данными:
- `filter_by_currency()` - фильтрация по валюте
- `transaction_descriptions()` - генератор описаний

### find.py
Поиск и анализ:
- `process_search_bank()` - поиск по ключевым словам
- `process_bank_operations()` - статистика по категориям
